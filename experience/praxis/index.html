An answer is not evidence of success.

A model can produce a fluent answer and still miss the task. An agent can claim to issue a refund without changing the purchase state. An HTTP application can respond successfully while violating its response contract.

Praxis binds versioned scenarios to inputs, output schemas and executable assertions. Its local runner uses distinct adapters for models, permissioned tool agents and HTTP applications, then persists the raw outputs, checks, timing and traces needed to inspect a failure.

    Run the original Praxis locally.

    Praxis is open source under the MIT License. Controlled-beta qualification covers Linux and macOS 15 within the documented local-first scope. Native Windows is currently unsupported. Source installation is required; prebuilt installers are not available.

    You need Python 3.12, Node.js 22.12+, npm and a POSIX-compatible shell. Demo fixtures need no cloud account or model download. Real inference requires your own configured model endpoint.

    git clone -b codex/praxis-final-release https://github.com/akilanpl/praxis.git
cd praxis
./scripts/setup.sh
npm run dev

    Create a local account in the development UI after launch. Keep the local control plane private. Chromium is needed for browser checks, not ordinary model, agent or HTTP evaluations. The installation and recovery guide covers built-mode launch, verified backups and interrupted runs.

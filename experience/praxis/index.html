Praxis

A local evaluation workspace for engineering teams building models, tool-using agents, and HTTP applications.

In development

From a failed check to its cause

Praxis is intended to turn product requirements into versioned, executable scenarios. Each scenario defines the input, the expected output shape, and the checks that determine whether the system met the requirement. The runner is designed to retain raw responses, assertion results, tool traces, timing, and run configuration so an engineer can trace a failure back to the evidence.

When a team changes a model, prompt, or tool policy, Praxis aims to make it possible to rerun the same scenarios under matching conditions and see which checks changed. The intended use is regression review for a specific system, where the team can inspect what happened before deciding whether to ship.

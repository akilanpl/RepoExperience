PLAN REVIEW · VERSION 1

Is this plan okay?

  1. Create rangoli.py using Python’s standard turtle module. Set up a 520 × 520 dark canvas.
  2. Draw three radial rings of petals, with 16, 16, and 8 petals. Rotate through four colors, then add concentric borders and 32 diamonds.
  3. Animate one stroke every 48 ms. Export the same drawing coordinates for this browser preview.
  4. Check that the 75 strokes use valid points within the canvas before revealing the drawing.

This guided example supports the approval path.
